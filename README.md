# Customer Contact List Cleanup & Standardization

A beginner-level data entry and cleaning project built in Microsoft Excel. 
This project simulates a real-world scenario where a raw customer database 
contains duplicates, inconsistent formatting, and invalid entries — and 
demonstrates how to clean, standardize, and validate that data.

## 📋 Project Overview
Raw customer data is rarely clean. This project takes a messy customer 
contact list and transforms it into a standardized, validated dataset 
ready for business use.

## 🔧 What Was Done
- **Removed duplicate records** using Excel's Remove Duplicates tool
- **Standardized name formatting** to proper case (e.g., "ahmed khan" → "Ahmed Khan")
- **Standardized phone number formatting** into a consistent format (03XX-XXXXXXX)
- **Fixed malformed email addresses** and flagged invalid entries
- **Applied Data Validation rules** on Phone and Email columns to prevent 
  incorrect entries going forward
- Built a **before/after comparison** to clearly show the cleanup impact

## 📁 File Structure
- `Raw Data (Before)` — original messy dataset with highlighted errors
- `Cleaned Data (After)` — standardized, deduplicated dataset with validation rules
- `Cleanup Summary` — key metrics on records cleaned, duplicates removed, and corrections made
